# M5-mirror — все сервисы M5 в одном репозитории

Полная копия наработок, поставленных на серверы M5 VPN, чтобы всё можно было поднять с нуля
из одного места. Каждый сервис также лежит в отдельном репозитории.

| Папка | Сервис | Отдельный репозиторий |
|---|---|---|
| `analytics/` | Маскировка CDN-туннеля под веб-аналитику «M5 Service»: umami, витрина, nginx источников (Москва, СПб), профиль xray `M5-CDN-ORIGIN`, синхрон сертификата | M5-analytics |
| `subscription/` | Получение и обновление подписки через изолированный CDN `s.m5service.name`, витрина-маскировка на корне домена | M5-subscription |
| `geo/` | Гео-файлы через свой CDN: зеркало Loyalsoldier + автообновление у клиентов (`LastUpdated`) | M5-geo |
| `server/m5_harden.sh` | Регламент серверов: файрвол (порт ноды 62050 только с панели, порты релеев только с разрешённых адресов, исходящая почта закрыта), fail2ban, UTC, автообновления, еженедельный рестарт ноды | — |

## Домены

| Домен | Назначение |
|---|---|
| `media.m5service.ws` | CDN-туннель (обход белых списков), маскировка под аналитику |
| `o2.m5service.ws`, `app.m5service.ws` | источники CDN-туннеля (Москва, СПб) |
| `s.m5service.name` | CDN подписки и гео (отдельный аккаунт Яндекса) |
| `orgn.m5service.name` | источник подписки и гео (сервер панели) |

## Регламент серверов

```bash
# пример для источника CDN (без авторебута)
COMPOSE_DIR=/opt/remnanode CRON_MIN=0 CRON_HOUR=4 bash server/m5_harden.sh
```
Параметры описаны в шапке скрипта. Скрипт идемпотентный — повторный запуск ничего не ломает.

## Секреты

В репозитории их нет: токен панели, пароли umami, ключи нод и сертификаты живут только на
серверах (`.env`, `/etc/m5-geo/panel.env`, certbot). Шаблоны — `*.env.example`.
